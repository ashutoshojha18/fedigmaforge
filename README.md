# Fedigma Forge - React & Node.js Website

A modern, responsive website built with React.js frontend and Node.js backend, recreated from the original HTML/CSS/JS version.

## 🚀 Quick Start

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn
- Git

### Installation & Setup

1. **Clone the repository**
   ```bash
   git clone <your-repo-url>
   cd fedigma-forge-react
   ```

2. **Install dependencies**
   ```bash
   npm run install-all
   ```

3. **Start development servers**
   ```bash
   npm run dev
   ```

   This will start:
   - React frontend on http://localhost:3000
   - Node.js backend on http://localhost:5000

### Individual Commands

- **Start only frontend**: `npm run client`
- **Start only backend**: `npm run server`
- **Build for production**: `npm run build`
